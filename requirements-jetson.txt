# Dependencies for NVIDIA Jetson Orin Nano (JetPack 6.x, aarch64)
#
# torch and torchvision are deliberately NOT listed here.
# PyPI publishes no aarch64 Linux wheels with CUDA support, so
#   pip install torch
#   pip install torch torchvision --index-url https://pytorch.org/whl/cu121
# BOTH FAIL on a Jetson. Install them separately from NVIDIA - see the
# "Install torch on the Jetson" section of README.md.
#
# Verified target: JetPack 6.2 / 6.2.1 (Jetson Linux 36.4.3 / 36.4.4),
# CUDA 12.6, TensorRT 10.3, cuDNN 9.3, Ubuntu 22.04, Python 3.10, aarch64.
# Orin Nano compute capability is sm_87.

#     gst-inspect-1.0 nvv4l2h264enc
#
# --- OpenCV caveat ----------------------------------------------------------
# JetPack provides its own CUDA-enabled OpenCV as the system `cv2`. Installing
# the pip `opencv-python` above inside a venv created WITHOUT
# --system-site-packages gives you a CPU-only OpenCV, and
# `import cv2` can fail with a numpy/cv2 ABI mismatch.
# Either:
#   a) python3 -m venv --system-site-packages .venv   (reuses JetPack cv2), or
#   b) pip install --no-deps opencv-python==4.10.0.84
# See the README section "OpenCV and JetPack" before choosing.
